### 常量/加减乘除模块

在matlab中 如果你将这个元素看作向量形式 那么这个元素就是竖向排列的形式

**向量被解释为一维数组**：
无论输入是行向量（`[1 2 3]`）或列向量（`[1;2;3]`），统一视为 **长度为 N 的一维向量**（不区分行列）

![image-20250621212724744](./Simulink%E5%AD%A6%E4%B9%A0.assets/image-20250621212724744.png)

如果你将这个元素看作矩阵的形式，那么这个元素就是按照你的书写格式排列的

输入的向量参数（如 `[1 2 3 4 5 6 7 8 9]`）会被视为：

- 行向量 → **1×N 矩阵**（例如 `[1 2 3]` 是 `1×3`）
- 列向量 → **N×1 矩阵**（例如 `[1;2;3]` 是 `3×1`）

| `isFinite` | 如果输入为有限值，则为 TRUE |

### 离散时间积分模块

#### 欧拉法

📘 假设我们要解的微分方程是：

$\frac{dy}{dt} = f(t, y), \quad y(t_0) = y_0$

我们希望用数值方法在离散时间点$ t_n = t_0 + nh$（步长为 hh）上，逐步计算 $y_n≈y(t_n)$

##### 前向欧拉法（Forward Euler）

✅ 公式：

$y_{n+1} = y_n + h \cdot f(t_n, y_n)$

🧠 特点：

- **显式方法**：右侧的值都是已知的。
- **优点**：简单、计算量小。
- **缺点**：稳定性差，对刚性问题不适合（容易发散）。

🧪 示例：

设 $\frac{dy}{dt} = -ky$，用前向欧拉法：

$y_{n+1} = y_n - hk y_n = y_n(1 - hk)$

##### 🔹 二、后向欧拉法（Backward Euler）

✅ 公式：

$y_{n+1} = y_n + h \cdot f(t_{n+1}, y_{n+1})$

🧠 特点：

- **隐式方法**：右边包含未知的 $y_{n+1}$，所以通常需要解一个方程（非线性的需要迭代或牛顿法）。
- **优点**：数值稳定性好，适合**刚性系统**。
- **缺点**：计算复杂度高，可能需要迭代求解。

🧪 示例：

对于 $y\frac{dy}{dt} = -ky$：

$y_{n+1} = y_n - hky_{n+1} \Rightarrow y_{n+1}(1 + hk) = y_n \Rightarrow y_{n+1} = \frac{y_n}{1 + hk}$

对比前向欧拉的$y_{n+1} = y_n(1 - hk)$，你会发现前向法不稳定时，后向法依然能收敛。

🔄 前向 vs 后向 总结对比表：

| 特性       | 前向欧拉法           | 后向欧拉法             |
| ---------- | -------------------- | ---------------------- |
| 类型       | 显式方法             | 隐式方法               |
| 计算复杂度 | 低                   | 高（可能要解方程）     |
| 稳定性     | 差                   | 好（适合刚性系统）     |
| 应用场景   | 简单系统，非刚性问题 | 刚性系统，稳定性要求高 |

🧩 补充说明：什么是“刚性系统”？

刚性系统指的是：系统中不同变量的变化速率差异很大，或者存在多个时间尺度，容易导致数值方法发散。这类系统用前向欧拉法就很不稳定，而后向欧拉法更适合。

------

如果你是做控制、模拟或电机系统建模（比如你之前提到的电机控制），刚性系统很常见，比如电感、电容导致的高阶微分方程就可能刚性。
